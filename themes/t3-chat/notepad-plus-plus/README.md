# Notepad++ input

`stylers.model.xml` is Notepad++'s list of languages and style IDs, copied unmodified from
[notepad-plus-plus/notepad-plus-plus](https://github.com/notepad-plus-plus/notepad-plus-plus/blob/ddef5e0fc863f02cd7c8330dc8c45cb6e1cef0de/PowerEditor/src/stylers.model.xml)
(GPL-3.0). `scripts/t3_chat_theme.py` recolors it into the T3 Chat themes for Notepad++.
