# T3 Chat Theme

The **T3 Chat** palette from [T3 Code](https://github.com/pingdotgg/t3code) for VS Code, in light and dark. Syntax highlighting uses [Pierre](https://github.com/pierrecomputer/pierre), the same token colors T3 Code uses for code blocks and diffs, so code looks the same in both apps.

The terminal keeps VS Code's default ANSI colors, which is also what T3 Code's terminal uses.

Generated from `themes/t3-chat/palette.json` in [rmotafreitas/dotfiles](https://github.com/rmotafreitas/dotfiles) by `scripts/t3_chat_theme.py`.
